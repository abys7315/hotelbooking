# Aurora Hotel Website Starter Pack

This folder is prepared to give to Antigravity as the working project folder.

## Contents
- `reference_boards/`: three cinematic design/storyboard references.
- `images/`: cropped visual-reference panels from the concept board. These are **reference crops**, not standalone original hotel photos.
- `docs/ANTIGRAVITY_MASTER_PROMPT.md`: full implementation prompt.

## How to use
1. Extract this folder somewhere convenient.
2. Open this exact folder as the workspace/project in Antigravity.
3. Open `docs/ANTIGRAVITY_MASTER_PROMPT.md`, copy the full prompt, and paste it into Antigravity.
4. Tell Antigravity to treat this folder as the project root and to build the actual working website here.
5. If you have the Saffron & Smoke restaurant website recording, add it to `reference_boards/` before starting so Antigravity can study the real scroll behavior.

## Important
The included images establish visual direction. They are not a complete collection of separate production-ready hotel photographs. The prompt instructs Antigravity to source or create individual, properly licensed images and organize them for the finished site.
